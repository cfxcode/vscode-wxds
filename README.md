# 微信读书助手 (vscode-wxds)

一款基于**微信读书官方 Agent API Gateway** 构建的纯净安全版 Visual Studio Code 插件：不依赖网页反代、不注入第三方页面脚本、**零账号风控风险**。

在 VS Code 内即可管理个人书架、查看阅读统计与偏好分析看板、浏览书籍详情/目录/热门划线/公开书评、书城多维搜索，并支持将个人笔记与划线一键导出为 Markdown；需要阅读正文时，一键跳转官方微信读书网页版安全阅读。

## 核心功能

### 1. 侧边栏 4 大视图（官方 API 驱动，免扫码）
- **我的书架**：准确统计电子书、有声书/专辑、文章收藏入口及公开/私密数量，支持一键查看书籍详情、浏览器打开阅读、导出笔记与找相似好书。
- **我的笔记与划线**：自动拉取全量笔记本（含划线、想法/点评、书签统计），支持在侧边栏直接展开浏览划线与想法。
- **阅读概况与统计**：快速展示本月/本年/累计阅读时长、有效阅读天数、阅读偏好及最近 5 本书的阅读进度。
- **发现与推荐**：个性化「为你推荐」、相似好书推荐，以及支持 9 种范围（电子书、全部、网文、听书、作者、全文、书单、公众号、文章）的书城多维搜索。

### 2. 可视化面板与一键导出 Markdown
- **阅读统计与偏好看板**：支持 `本周 / 本月 / 本年 / 全部总计` 切换，展示读书时长排行、分类偏好分布、偏好作者与出版社等。
- **书籍详情面板**：一站式查看书籍简介、完整章节目录、个人进度、热门划线（Top 20）及多维度筛选的公开书评（全部 / 推荐 / 最新 / 一般 / 不行），并支持一键跳转微信读书网页版正文。
- **Markdown 笔记导出**：支持单本导出或全量批量导出，自动生成包含 YAML Frontmatter、按章节分组的划线引用与个人想法的 `.md` 文件。

### 3. 安全合规设计
- **纯官方 API 网关**：全部数据查询均走官方 `https://i.weread.qq.com/api/agent/gateway`，使用官方 `WEREAD_API_KEY` 鉴权。
- **密钥加密存储**：通过 VS Code `SecretStorage` 安全保存密钥，或自动读取系统环境变量 `WEREAD_API_KEY`，不写入任何明文配置文件。
- **无反代 / 无网页劫持**：不通过本地反代或 iframe 嵌入微信读书网页正文，避免触发微信读书官方第三方插件风控提示。

## 快速开始

### 1. 安装依赖与打包
```bash
npm install
npm run test
npm run package
```
执行后会在当前目录生成 `vscode-wxds-0.2.0.vsix`，通过以下命令或 VS Code 的 `Extensions: Install from VSIX...` 安装：

```bash
code --install-extension vscode-wxds-0.2.0.vsix
```

### 2. 配置 API Key
支持以下任一方式（优先级从高到低）：
1. **推荐（加密存储）**：在 VS Code 命令面板运行 `微信读书: 配置 API Key`，输入 `wrk-xxxxxxxx` 格式密钥。
2. **环境变量自动读取**：在 `~/.zshrc` 或系统环境中配置 `export WEREAD_API_KEY="wrk-xxxxxxxx"`，插件启动时自动读取。

## 配置项说明

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `wxds.showStatusBar` | `true` | 是否在底部状态栏显示微信读书快捷菜单入口 |
| `wxds.exportDir` | `weread-notes` | Markdown 笔记默认导出目录（相对工作区根目录） |
| `wxds.apiGateway` | `https://i.weread.qq.com/api/agent/gateway` | 官方 Agent API Gateway 地址 |

## 常用命令

- `微信读书: 打开快捷菜单`（点击底部状态栏 `微信读书` 按钮）

- `微信读书: 书城多维搜索`
- `微信读书: 一键导出全部笔记划线为 Markdown`
- `微信读书: 在浏览器中打开阅读`
- `微信读书: 配置 API Key`
