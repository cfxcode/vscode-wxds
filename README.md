# 微信读书助手 (vscode-wxds)

一款全功能的 Visual Studio Code 微信读书插件：既支持通过**本地反向代理 + Webview** 在 VS Code 内直接阅读微信读书正文（支持隐蔽标题、透明度调节、隐藏滚动条、老板键、Remote SSH 端口转发），又深度接入**微信读书官方 Agent API Gateway**，提供书架管理、阅读统计与偏好分析看板、书城多维搜索、热门划线与书评浏览、以及笔记划线一键导出 Markdown。

## 核心功能

### 1. VS Code 内嵌微信读书阅读器
- 点击底部状态栏 `微信读书` 或左侧书架中的任意书籍，即可在 VS Code 编辑器标签页内直接阅读正文。
- **隐蔽 / 摸鱼定制**：
  - 自定义标签页标题（如改成 `utils.ts`）与隐藏 Logo
  - 实时调节阅读器透明度（`0.15` ~ `1.0`）
  - 一键隐藏右侧滚动条
  - **老板键**（默认 `Alt+Shift+W`）：一键隐藏/恢复阅读器并记住上次阅读位置
- **远程开发适配**：基于 `vscode.env.asExternalUri`，自动兼容 Remote SSH / WSL / DevContainer 端口转发。
- **零第三方运行时依赖**：纯 Node.js 原生 `http/https` 实现本地反向代理，并内置「在浏览器中打开」随时兜底。

### 2. 侧边栏 4 大视图（官方 API 驱动，免扫码）
- **我的书架**：准确统计电子书、有声书/专辑、文章收藏入口及公开/私密数量，支持一键内嵌阅读、外部打开、查看详情与导出笔记。
- **我的笔记与划线**：自动拉取全量笔记本（含划线、想法/点评、书签统计），支持在侧边栏直接展开浏览划线与想法。
- **阅读概况与统计**：快速展示本月/本年/累计阅读时长、有效阅读天数、阅读偏好及最近 5 本书的阅读进度。
- **发现与推荐**：个性化「为你推荐」、相似好书推荐，以及支持 9 种范围（电子书、全部、网文、听书、作者、全文、书单、公众号、文章）的书城多维搜索。

### 3. 可视化面板与一键导出 Markdown
- **阅读统计与偏好看板**：支持 `本周 / 本月 / 本年 / 全部总计` 切换，展示读书时长排行、分类偏好分布、偏好作者与出版社等。
- **书籍详情面板**：一站式查看书籍简介、完整章节目录、个人进度、热门划线（Top 20）及多维度筛选的公开书评（全部/推荐/最新/一般/不行）。
- **Markdown 笔记导出**：支持单本导出或全量批量导出，自动生成包含 YAML Frontmatter、按章节分组的划线引用与个人想法的 `.md` 文件。

## 快速开始

### 1. 安装依赖与打包
```bash
npm install
npm run test
npm run package
```
执行后会在当前目录生成 `vscode-wxds-0.1.0.vsix`，在 VS Code 中执行命令 `Extensions: Install from VSIX...` 即可本地安装。

### 2. 配置 API Key（用于书架 / 统计 / 笔记 / 搜索）
支持以下任一方式（优先级从高到低）：
1. **推荐（加密存储）**：在 VS Code 命令面板运行 `微信读书: 配置 API Key`，输入 `wrk-xxxxxxxx` 格式密钥（存入 VS Code `SecretStorage`，不写入明文设置文件）。
2. **环境变量自动读取**：在 `~/.zshrc` 或系统环境中配置 `export WEREAD_API_KEY="wrk-xxxxxxxx"`，插件启动时自动读取。

> 说明：内嵌阅读器加载微信读书网页版正文使用微信读书网页登录态，与 API Key 相互独立。

## 配置项说明

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `wxds.showStatusBar` | `true` | 是否在底部状态栏显示微信读书快捷入口 |
| `wxds.readerTabTitle` | `微信读书` | 阅读器标签页标题（可自定义为代码文件名等） |
| `wxds.showTabLogo` | `true` | 是否在阅读器标签页上显示图标 |
| `wxds.readerOpacity` | `1` | 阅读器页面不透明度（`0.15` ~ `1.0`） |
| `wxds.hideScrollbar` | `false` | 是否隐藏阅读器右侧滚动条 |
| `wxds.proxyPort` | `0` | 本地反向代理端口（`0` 表示自动分配空闲端口） |
| `wxds.exportDir` | `weread-notes` | Markdown 笔记默认导出目录（相对工作区） |
| `wxds.apiGateway` | `https://i.weread.qq.com/api/agent/gateway` | 官方 Agent API Gateway 地址 |
